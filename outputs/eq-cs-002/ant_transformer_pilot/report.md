## 试验怎么做

用 Quant-Research-Lab 的导入器重建 lab.duckdb。快照 quant-lab-data-v1.0.0 的所有 Parquet 校验和通过，10 张表合计 45,438,121 行，与 manifest 一致。数据通过框架的 load_prices、load_universe_panel 与 load_calendar 读取，月末资格以当时可见的标普 500 成分快照为准。

每只股票用六个连续月末的五个特征，分别为 20 日动量、60 日动量、12–1 月动量、60 日总波动率、20 日对 120 日均量比的对数。各月分别进行 1% 和 99% 缩尾及截面标准化。下一交易日开盘按调整因子换算价格入场，下一次月度调仓开盘退出。测试期无缺失入场报价，有 17 条缺失出场开盘报价，以截至该日之前最近的复权收盘价估算，退市结算价格和实际交易结果可能不同。

| 切分 | 信号日期 | 月数 | 股票月样本 |
|---|---|---:|---:|
| train | 2012-05-31 至 2023-10-31 | 138 | 59,251 |
| validation | 2024-01-31 至 2024-10-31 | 10 | 4,858 |
| test | 2025-01-31 至 2026-07-31 | 19 | 9,314 |

训练和验证均剔除在阶段结束之后才兑现的标签。历史特征窗口可以跨切分边界。神经网络统一为 4 层、宽度 32，保留原模型的首 token 读出。所有学习模型使用同一输入和截面收益秩目标。四种结构各训练两个种子，每个种子训练 5 轮，以验证 Rank IC 选轮次。两种子的输出先在截面内转成百分位，再取平均。

原模型默认 A 股六因子、宽度 256、损失拟合原始收益。本试验用美股价量数据、较窄的网络和收益秩 MSE，检验其结构在这一设定下的表现。门控开启时使用原系数 0.08 的门控正则，因此门控对照同时包含正则项的影响。

## 源码里的几个关键点

- 前向先完整计算注意力和 FFN，再用 sigmoid 门控插值。门值趋近零时，输出靠近层输入，前面的计算已经执行。
- 第一层没有历史，门控输入为全零，因而只学习一组与样本无关的通道权重。关掉跨层注意力时，四层的门控均如此。已用随机输入核对门控随样本和时间位置的变化。
- 跨层模块内部返回当前隐状态加注意力输出，外层再次加入当前隐状态。带历史的层归一化前实际使用两份当前隐状态加一份注意力输出。结构消融保留了这段代码。
- 金融路径读取最旧月份的位置，没有插入专用 CLS token。这个位置经过自注意力仍可读取窗口内各月。
- 原流程先分数据再分别建滑窗，边界后会损失前几个月的样本。可选 IC 损失在随机混入多个日期的 batch 上算 Pearson 相关，和验证时逐月计算 IC 的目标不一致。训练入口构建了测试加载器，最终输出使用验证集。

## 复跑

使用 Python 3.12。在 Quant-Research-Lab 旁边检出上文链接所示的 ant-transformer 版本，在 Quant-Research-Lab 根目录执行下列命令。将 QUANT_LAB_SNAPSHOT 指向冻结快照根目录，里面须有 manifest.json 和 data/。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e . -e ../ant-transformer pytest
QUANT_LAB_SNAPSHOT=/path/to/quant-lab-data-v1.0.0 python tools/restore_ant_pilot_db.py
python -m pytest -q tests/test_ant_transformer_pilot.py
python -m quant_research_lab.experiments.ant_transformer_pilot
```

建新库时会校验全部 Parquet 文件和表行数。已有同名库时脚本仅核对行数，验证冻结快照时可从新工作目录恢复。
