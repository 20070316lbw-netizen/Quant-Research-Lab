# 中国地级市宏观与环境数据库 (`cn_macro`) 说明文档

本文档完整记录中国地级市宏观与环境数据集的架构定位, 数据源, 清洗与计算口径, 质量体检结果, 交付物清单及可复现恢复方式。

## 1. 架构定位与托管方案

- **完全独立于美股主库**: 本地数据库为 `data/cn_macro/cn_macro.duckdb` (DuckDB `2.0.1`), 零修改美股 `data/lab.duckdb`。
- **无 CLI 参数驱动**: 全部路径, 起止年份与远端路径统一由 `configs/cn_macro_build.yaml` 配置管理。
- **三轨落盘形态 (同源一致)**:
  1. **本地查询库**: `data/cn_macro/cn_macro.duckdb`
  2. **Parquet 快照与校验清单**: `data/cn_macro/parquet/` (ZSTD 压缩 + `manifest.json` 含行数, Schema 与 SHA256)
  3. **独立 Excel 交付件**: `data/cn_macro/deliverables/` 下 4 份 `.xlsx` 文件, 严格按目标列名导出, 便于逐个手动上传至外部平台
- **Hugging Face 远端托管**:
  - 仓库: `2007liuQuant/Quant-Research-Lab` (Dataset)
  - 独立子目录: `cn_macro/` (与美股 `data/` 互不干扰)
  - 首次上传提交: `10a06566b330af16d21a71dbbb835a65a510bd87`

## 3. 权威数据源与处理口径

### 3.1 统一中国地级市行政边界底座 (`geo.py`)
- **来源**: 阿里云 DataV.GeoAtlas `areas_v3` 公开边界接口 (`100000_full.json` 与内地 31 省 `{adcode}_full.json`), 本地缓存在 `data/cn_macro/raw/geojson/`。
- **范围**: 包含 4 个直辖市 (`110000` 北京市, `120000` 天津市, `310000` 上海市, `500000` 重庆市) 及 27 个省/自治区下辖全部地级市, 自治州, 盟与省直辖县级行政区, 排除港澳台 (`710000`, `810000`, `820000`), 共 **367 个标准地级行政单元多边形**。
- **一致性**: `cn_city_pm10` 与 `cn_city_carbon` 共用同一套 367 市边界与 6 位国标码 (`CITY_ID`, `PR_ID`), 确保两张宽表逐行严格对齐。

### 3.2 地级市逐年 PM10 (`pm10.py`)
- **来源**: **CHAP (`ChinaHighPM10` V4)** 韦晶团队开源 1km 空间分辨率年度 NetCDF 栅格:
  - 2000-2021 年: Zenodo 记录 `3752465` (`10.5281/zenodo.3752465`)
  - 2022-2025 年: Zenodo 概念记录 `10475457` (解析至最新版本 `21773535`)
  - 文件命名: `CHAP_PM10_Y1K_<YYYY>_V4.nc` (每文件 7.8-9.4 MB, 网格尺寸 `3571 × 6148`, 约 0.01 度分辨率)
- **原始编码与聚合**:
  - 变量 `PM10` 为 `uint16`, `_FillValue=65535`, `scale_factor=0.1`, 单位 `ug/m3`。
  - 使用 `rasterio.features.rasterize(..., all_touched=True)` 将 367 个城市多边形一次性栅格化为标签矩阵, 每年用 `np.bincount` 向量化计算有效像元均值并保留 3 位小数。
- **核验样本**:
  - 北京市 (`110000`): 2000 年 **`104.294`** -> 2024 年 **`59.375`** -> 2025 年 **`52.528`** `ug/m3`。

### 3.3 中国各城市碳排放 (`carbon.py`)
- **来源**: 欧盟联合研究中心 (JRC) **EDGAR 2025 GHG** 全球总 CO2 排放年度 NetCDF 栅格 (`EDGAR_2025_GHG_CO2_<YYYY>_TOTALS_emi_nc.zip`, 覆盖 2000-2024 年)。
- **原始编码与高精度空间加总**:
  - 原始网格为全球 `1800 × 3600` (0.1 度, 纬度由南向北升序 `-89.95 -> +89.95`), 变量 `emissions` 单位 `Tonnes` (2024 全球总量 `39.63 Gt`)。
  - 先裁剪中国外接矩形 `[15N..56N, 72E..136E]`, 纬度轴上下翻转对齐北到南栅格顺序;
  - 对 0.1 度网格做 **5 倍子网格过采样 (0.02 度)** 并将单格排放均分至 25 个子格, 显著提升小面积城市 (如深圳, 厦门, 东莞) 边界重叠分配精度; 若极小单元无中心命中则用 `all_touched=True` 兜底;
  - 按城市求和并除以 `1e6` 换算为 **`Mt CO2` (百万吨)**, 保留 4 位小数。
- **核验样本**:
  - 2024 年全国 367 城合计: **`12,294.7 Mt` (12.29 Gt)**, 与中国年度化石能源 CO2 总排放量级高度吻合。
  - 北京市 (`110000`): 2000 年 **`42.8443 Mt`** -> 2024 年 **`79.6579 Mt`**。

### 3.4 统计年鉴与 296 地级市 2000 基期 GDP (`yearbook_gdp.py`)
- **源表**: `data/统计年鉴数据.xlsx` (1990-2023 年, 300 城市, 217 列)。
- **300 市 -> 296 地级市过滤规则**:
  剔除 4 个已撤销或无常规 GDP 的特殊行政单元:
  1. `341400` 巢湖市 (2011 年撤销拆分)
  2. `371200` 莱芜市 (2019 年并入济南市)
  3. `460300` 三沙市 (人口极少, 无常规 GDP 公布)
  4. `632500` 海南藏族自治州 (青海自治州, 非地级市)
- **2000 基期不变价 GDP 精确计算公式**:
  - `名义GDP` (亿元) = `地区生产总值(万元) / 10000`
  - `GDP指数` (2000=100): 2000 年定基为 `100.0`, 此后逐年按官方 `地区生产总值增长率(%)` 累乘: `Index[t] = Index[t-1] * (1 + g[t] / 100)`
  - `实际GDP` (2000 年不变价, 亿元) = `名义GDP[2000] * (GDP指数[t] / 100)`
  - `GDP平减指数` = `(名义GDP[t] / 实际GDP[t]) * 100`
- **2000 年尚未撤地设市的 21 个城市衔接规则**:
  - 涉及 21 市: 来宾市, 崇左市, 三沙市 (已剔除), 儋州市, 丽江市, 临沧市, 拉萨市, 日喀则市, 昌都市, 林芝市, 山南市, 那曲市, 商洛市, 庆阳市, 定西市, 陇南市, 海东市, 固原市, 中卫市, 吐鲁番市, 哈密市。
  - 绝不在 2000 年虚构名义 GDP; 在其首个可观测年份 `t0`, 用同省城市中位 GDP 平减指数 (省级缺失则用全国中位数) 锚定 2000 基期实际 GDP (`real0 = nom0 / (defl0 / 100)`), 此后各年严格使用该市自身官方实际增速累乘。
- **核验样本 (北京市, 单位: 亿元)**:
  - `2000`: 名义 `2,478.76` | 指数 `100.0000` | 实际 `2,478.7600` | 平减 `100.0000`
  - `2010`: 名义 `14,113.58` | 指数 `289.9641` | 实际 `7,187.5148` | 平减 `196.3624`
  - `2020`: 名义 `36,103.00` | 指数 `551.0337` | 实际 `13,658.8024` | 平减 `264.3204`
  - `2023`: 名义 `43,761.00` | 指数 `633.3636` | 实际 `15,699.5632` | 平减 `278.7402`

## 4. 数据质量体检报告

### 4.1 原始《统计年鉴数据.xlsx》体检结果
- **骨架完整性**: `10,200` 行 × `217` 列 = `34` 年 (1990-2023) × `300` 城 (31 省), 主键 `(年份, 城市)` 与 `(年份, 城市代码)` **0 缺失, 0 重复**; `城市` 与 `城市.1` 100% 相同。
- **区域分布**: 东部 `3,502` 行, 中部 `3,434` 行, 西部 `3,264` 行; 胡焕庸线东南侧 `9,146` 行, 西北侧 `1,054` 行。
- **数据类型**: 208 个指标列中 **0 个非数字脏文本**。
- **GDP 逻辑体检 (2000-2023)**:
  - `0` 个 `<= 0` 的异常 GDP;
  - `0` 个单年同比 `> 2.5 倍` 或 `< 0.4 倍` 的异常跳变;
  - 三产增加值加总与 GDP 相对误差 `> 5%` 仅 `36 / 6,953` (0.5%);
  - 2004-2023 年在 296 有效城市中, 核心指标 (GDP, GDP 增速, 人均 GDP, 地方财政, 社零) 覆盖率达 **96%-99%**。
- **2000-2023 列级缺失分布 (208 个指标列)**:
  - `< 10%` 缺失: 38 列 | `10%-30%`: 40 列 | `30%-60%`: 49 列 | `60%-90%`: 58 列 | `>= 90%`: 23 列
  - 缺失主因是统计年鉴历次指标改版 (非数据损坏):
    - `工商税收(万元)`: 2000-2023 全空 (100% 缺失)
    - `常住人口(万人)`: 2020 年起才有记录
    - `全年用电量(万千瓦时)`: 2017 年起才有记录
    - `户籍人口(万人)`: 2023 年停报
    - 2003 年前后存在《国民经济行业分类》旧 15 行业与新 19 行业从业人员列切换
    - 2011 年起规模以上工业企业统计门槛由 500 万元调整为 2,000 万元
- **基表防污染原则**: 所有原始缺失值均保持 `NaN`, 不在基表层擅自线性插值或均值填充。

### 4.2 派生 296 市 GDP 表缺失统计 (2000-2023, 共 7,104 行)
- 标识列 (`省份`, `城市`, `年份`, `城市年份`): `0` 缺失
- `名义GDP`: `186` 缺失 (主要集中在 2000-2003 年尚未设市城市)
- `GDP指数` / `实际GDP` / `GDP平减指数`: 各 `393` 缺失

### 4.3 关于 2024 年 296 市 GDP 的口径说明与扩展预留
- 排查公开平台后, 聚汇数据页面单元格为前端受限/空值, 维基百科仅覆盖至 2022-2023, GitHub 暂无完整 296 市 2024 开放 CSV。
- 更关键的经济学口径风险: 2024 年底公布了**第五次全国经济普查 (五经普)**, 2023 年名义 GDP 被整体上修约 5%-10% (如北京, 上海均大幅上修), 而当前年鉴是五经普前口径; 直接硬拼 2024 公报数会导致 2024 年名义 GDP 与平减指数出现人为断层。
- 代码已实现并测通 `append_yearbook_gdp_rows(yb_df, gdp_2024_df, year=2024)`, 后续拿到统一口径的 2024 地级市表后可直接追加并一键重算与刷新交付件。

## 5. 代码模块与一键恢复用法

### 模块清单 (`src/quant_research_lab/cn_macro/`)
- `config.py`: `load_cn_macro_config()` 读取并强校验 `configs/cn_macro_build.yaml`

- `pm10.py`: `download_chap_pm10_yearly()`, `build_city_pm10_table()`
- `carbon.py`: `download_edgar_co2_yearly()`, `build_city_carbon_table()`
- `yearbook_gdp.py`: `load_yearbook_xlsx()`, `append_yearbook_gdp_rows()`, `build_296_city_gdp_2000base()`
- `store.py`: `write_tables_to_duckdb()`, `export_cn_macro_to_parquet()`, `import_cn_macro_parquet_to_duckdb()`, `export_deliverables_xlsx()`, `push_cn_macro_to_hf()`, `pull_cn_macro_from_hf()`
- 单元测试: `tests/test_cn_macro.py` (覆盖解析解验证, 296 市过滤, Parquet 恢复与 SHA256 篡改拦截)

### 从 Hugging Face 一键恢复本地 DuckDB 与导出 Excel

```python
from pathlib import Path
from quant_research_lab.cn_macro import (
    export_deliverables_xlsx,
    import_cn_macro_parquet_to_duckdb,
    load_cn_macro_config,
    pull_cn_macro_from_hf,
)

cfg = load_cn_macro_config()
pq_dir = pull_cn_macro_from_hf(cfg)
db_path = import_cn_macro_parquet_to_duckdb(
    pq_dir,
    Path(cfg.paths.duckdb_path),
    verify_sha256=True,
)
export_deliverables_xlsx(db_path, Path(cfg.paths.deliverables_dir))
```
